# Java Practice Questions

This folder contains a collection of Java programming exercises focused on arrays, strings, pattern printing, and number theory. Each file is a small standalone program that solves a specific coding problem.

## Topics Covered

- String manipulation
- Array operations
- Pattern printing
- Prime and perfect number checks
- Frequency and counting problems
- Number conversion and bit-based logic

## Problem List

| File | Problem | What it does |
| --- | --- | --- |
| `Anagrams.java` | Check if two strings are anagrams | Compares character frequency of two strings to determine if they are anagrams. |
| `ArmstrongNumber.java` | Armstrong number check | Finds the first 4-digit Armstrong number in a range. |
| `CapitalizeFirstWord.java` | Capitalize words | Converts the first letter of each word into uppercase. |
| `CarryCount.java` | Carry count in addition | Counts how many times a carry occurs while adding two numbers. |
| `ConVoDigSpa.java` | Count characters | Counts vowels, consonants, digits, and spaces in a string. |
| `DecimalToBinary.java` | Decimal to binary conversion | Converts a decimal number into its binary form. |
| `Diamond.java` | Pattern printing | Prints a diamond shape using stars. |
| `FirstNonRepeating.java` | First non-repeating character | Finds the first character that appears only once in a string. |
| `FloydsTriangle.java` | Floyd's triangle | Prints a triangular number pattern. |
| `FrequencyOfChar.java` | Character frequency | Counts the frequency of each character in a string. |
| `Hourglass.java` | Hourglass pattern | Prints an hourglass-style alphabet pattern. |
| `MoveZeroes.java` | Zero movement | Moves all zeros to the end of the array while keeping non-zero values in order. |
| `NumberTriangle.java` | Number pattern | Prints a triangle of numbers. |
| `PasswordUsingPrime.java` | Prime-based password generation | Builds a password by appending prime numbers in sequence. |
| `Perfect.java` | Perfect number check | Checks whether numbers from 1 to 999 are perfect. |
| `Pyramid.java` | Pyramid pattern | Prints a star pyramid. |
| `RemoveArrayDup.java` | Remove array duplicates | Removes duplicate values from an integer array. |
| `RemoveDuplicates.java` | Remove repeated characters | Keeps only the first occurrence of each character in a string. |
| `ReverseArrayAddElm.java` | Reverse and sum array elements | Reverses an array and adds adjacent values. |
| `ReverseWordAppcount.java` | Reverse words and append length | Reverses each word and appends its length. |
| `ReverseWordCount.java` | Word reverse with count | Reverses each word and prints word length together with the reversed word. |
| `RotateArrayByk.java` | Array rotation | Rotates the elements of an array by k positions. |
| `StringCompression.java` | String compression | Compresses repeated characters into count + character pairs. |
| `StrongNumber.java` | Strong number check | Checks whether a number is a strong number by summing factorials of digits. |
| `Toggle.java` | Toggle case | Swaps uppercase and lowercase letters in a string. |

## How to Run

Each Java file can be compiled and run individually:

```bash
javac FileName.java
java FileName
```

Example:

```bash
javac Anagrams.java
java Anagrams
```

## Notes

These programs are beginner-to-intermediate Java exercises that help practice core concepts such as loops, conditionals, arrays, strings, and pattern-based problem solving.
